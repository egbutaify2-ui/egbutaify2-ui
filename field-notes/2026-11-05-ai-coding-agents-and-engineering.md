# AI coding agents are changing how we build software. But they aren't replacing engineering.

I've been spending a lot of time building software with AI-assisted development workflows, and one thing has become increasingly clear to me:

Getting code written is not the same as building a reliable system.

The interesting challenges often start after the code has been generated.

- Are the requirements actually understood?
- Does the implementation fit the existing architecture?
- Have the changes been properly reviewed?
- Does everything work together on the latest version?
- Has the result been tested rather than simply assumed to work?

AI coding agents can accelerate implementation, but they don't automatically understand the full context or own the consequences of a bad technical decision.

That's still an engineering responsibility.

I'm particularly interested in the intersection of AI agents, software architecture, context engineering and reliable software delivery.

We're entering an interesting era of software development.
